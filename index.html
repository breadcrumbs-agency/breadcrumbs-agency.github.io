breadcrumbs agency

Claude Haiku at DeepSeek Flash prices. breadcrumbs locks every Haiku 5.5 request under 100,000 tokens.

Anthropic charges five times as much per token for a Haiku 5.5 prompt over 100,000 tokens. breadcrumbs is the memory and context engine (ACE) for your agent. It folds the chat before a request crosses that step, so every request is billed at the low tier: $0.10 per million input tokens and $0.50 per million output tokens. That is below DeepSeek V4.1 Flash list price, off-peak.

How the lock works

  • ACE counts every input token of a request, cache reads and writes too, the way Anthropic counts the step.
  • breadcrumbs gives Haiku 5.5 a built-in ace_ceiling of 94,000 tokens. ACE's estimate read at most 5.9% under the model's own count on a live run, so 94,000 by the estimate stays under 100,000 on the bill.
  • A fold keeps every line it takes out: each one stays in memory under its address, and the model opens it again with crumb(id, level) when it needs it. Nothing is summarised away.
  • The ceiling comes from the price step in the cost profile. Any model with a price step gets one, and a models entry in config.json changes it.

Install (Hermes)

hermes plugins install breadcrumbs-agency/breadcrumbs-hermes --yes-deps --enable \
  --ref "$(git ls-remote https://github.com/breadcrumbs-agency/breadcrumbs-hermes refs/heads/release | cut -f1)"
hermes config set memory.provider breadcrumbs
hermes config set context.engine breadcrumbs     # ACE: this holds the price lock

Undo: hermes memory off, and set context.engine back to its earlier value.
